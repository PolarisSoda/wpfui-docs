# 리소스 키 전체 사전

[목차](README.md) · [조정 방법](CustomizationGuide.md) · [컨트롤별 조사 결과](CustomizationIndex.md)

기준 4.3.0의 Wpf.Ui XAML에 정의된 키 881개(문자열 862개·복합 키 19개)와 문서 대상의 참조를 함께 모았습니다. **키의 존재가 개별 컨트롤 Resources 재정의나 안정된 공개 API를 보장하지 않습니다.** StaticResource·중첩 범위·선택 스타일·미정의 이름을 개별 문서에서 확인합니다. x:Static·x:Type·ComponentResourceKey는 객체 키이므로 문자열과 사용 문법이 다릅니다. 자동 참조 추적은 문자열 키를 대상으로 하며 복합 키는 정의 목록과 수작업 사용 예제로 보완합니다. 라이브러리 외부 앱 리소스는 포함하지 않습니다.

파일 내 검색(Ctrl+F)으로 키를 찾은 뒤 링크를 열면 기본값·타입·정의 범위·사용 컨트롤을 확인할 수 있습니다. 큰 문서가 GitHub 표시 제한에 걸리지 않도록 세부 정의를 알파벳별 파일로 나눴습니다.
